# Store listing images

Generated by `npm run store` — do not hand-edit.

| File | Use |
|---|---|
| `screenshot-1..5-1280x800.png` | Chrome Web Store listing screenshots (preferred size) |
| `screenshot-1..5-640x400.png` | Same art, the smaller accepted size |
| `promo-tile-440x280.png` | Small promo tile |

Each slide composites the real popup renders from `design/`, which are
themselves rendered from the live `popup.html`. Nothing is a mockup, so a
listing image cannot show a UI the extension does not have.

The 640x400 files are the identical page at `deviceScaleFactor: 0.5`, not a
second layout — the two sizes cannot drift apart.

**Rule counts in the copy are read from the built artifacts at generate time.**
Re-run `npm run build && npm run design && npm run store` after changing
filters so the numbers on the images stay true.

The previous v2.1 "Data Saver" images are in `../OLD-screenshots-v2-DO-NOT-USE/`
— they show a three-toggle UI that no longer exists. Do not upload them.
